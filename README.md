# 🏥 Hospital Management Dashboard – Excel Data Analytics Project

## 📌 Project Overview

The **Hospital Management Dashboard** is an Excel-based data analytics project designed to analyze hospital operations, patient information, financial performance, and healthcare services.

This project uses a dataset of **5,000 patient records** to generate meaningful insights through Excel Pivot Tables, charts, and interactive dashboard filters.

The dashboard helps understand patient demographics, hospital departments, diseases, billing details, payment status, and patient satisfaction.

## 🎯 Project Objectives

- Analyze total patient records and patient demographics.
- Understand department-wise patient distribution.
- Identify the most common diseases.
- Analyze hospital revenue and billing amounts.
- Track paid and pending payments.
- Evaluate doctor and department performance.
- Analyze patient admission and discharge patterns.
- Understand patient feedback and satisfaction.

## 🛠️ Tools & Technologies Used

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Visualization
- Dashboard Development

## 📂 Dataset Description

The dataset contains 5,000 patient records with 29 columns.

| Category | Attributes |
|---|---|
| Patient Details | Patient ID, Patient Name, Gender, Age |
| Demographics | Age Group, Blood Group, City, State |
| Medical Details | Department, Doctor, Disease |
| Admission Details | Admission Date, Discharge Date, Stay Days |
| Hospital Facilities | Room Type, Bed Number |
| Financial Details | Bill Amount, Medicine Cost, Lab Charges, Room Charges, Doctor Fee |
| Insurance | Insurance, Insurance Company |
| Payment Details | Payment Mode, Payment Status |
| Patient Experience | Patient Status, Feedback Rating |
| Time Analysis | Month, Quarter |

## 📊 Dashboard Features

The interactive dashboard provides:

- Patient statistics and key performance indicators (KPIs).
- Department-wise patient analysis.
- Disease-wise patient distribution.
- Gender and age-group analysis.
- Revenue and billing analysis.
- Payment status analysis.
- Insurance analysis.
- Patient feedback analysis.
- Interactive slicers for filtering and exploring data.
